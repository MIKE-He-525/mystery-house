# Mystery House 评论台

> 把小红书或 Instagram 的评论贴进来，立刻分开购买意向、广告导流，和该回的问题。

一个诚实的工具，帮小店主和社交媒体运营者快速处理评论区，识别商机，清理垃圾。

## 这是什么

**Mystery House 评论台**是一个评论分类工具，专为小红书和 Instagram 的店主/运营者设计。

每天早上打开评论区，一堆"多少钱""有链接吗"混在"加微信""check my bio"的导流广告里。手动筛选费时费力，还容易漏掉真正想买东西的客户。

Mystery House 解决这个问题：

- **贴进来** - 把评论复制粘贴到工作台
- **点分类** - 一键自动分类成：要回复（购买意向）、广告/导流、其他
- **看结果** - 每条评论附带分类标签、原因说明、建议回复话术

不用 AI 密钥，不接平台 API，不自动发评论，不教绕过审核。只是帮你**省时间、不漏商机、清理垃圾**的人工辅助工具。

## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/MIKE-He-525/mystery-house.git
cd mystery-house
```

### 2. 安装依赖

```bash
npm install
```

### 3. 配置环境变量（可选）

复制 `.env.example` 为 `.env`：

```bash
cp .env.example .env
```

**注意：不配置环境变量也能正常使用核心功能**。环境变量仅用于：

- `STRIPE_*`：Pro 版收费功能（未配置时显示演示模式）
- `OPENAI_API_KEY`：AI 增强分类（未配置时使用纯规则分类）

### 4. 启动开发服务器

```bash
npm run dev
```

打开浏览器访问 [http://localhost:3000](http://localhost:3000)

### 5. 运行测试

```bash
npm test
```

## 使用方法

### 基础用法

1. 打开工作台（首页点击"打开工作台"）
2. 粘贴评论到文本框（支持三种格式）：
   - **纯文本**：每行一条评论
   - **用户名: 内容**：`小明: 多少钱？`
   - **TSV 格式**：`小明\t多少钱？\t5`（用户名、内容、点赞数）
3. 点击"开始分类"
4. 查看结果：
   - 🎯 要回复：重点关注，含建议回复
   - 🚫 广告/导流：建议删除或不回复
   - 💬 其他：普通评论，可选回复
5. 导出 CSV：点击"导出「要回复」CSV"下载购买意向评论

### 示例数据

点击"加载小红书示例"或"加载 Instagram 示例"可快速体验效果。

## 分类规则

### 🎯 要回复（购买意向/产品问题）

| 类型 | 关键词（中文） | 关键词（英文） | 建议回复 |
|------|----------------|----------------|----------|
| 询价 | 多少钱、多少、啥价、怎么卖、价格、包邮、优惠 | how much, price, cost, shipping | **站内回复**：引导至笔记商品卡/挂车或站内私信 |
| 产品问题 | 尺码、颜色、材质、有货、有m吗、链接、第几张、图几、怎么拿、po一下 | size, color, material, in stock, link | **站内回复**：商品卡详情或站内私信咨询 |
| 购买意向 | 想买、下单、求链接、有链接吗、怎么买、主页 | want to buy, order, purchase | **站内回复**：商品卡下单或站内私信 |

**重要说明**：

- ✅ **识别委婉询价**：小红书会过滤"价格""微信"等敏感词，买家常用"多少""第几张""图几"等委婉方式询问，工具能识别这些意图
- ✅ **建议回复合规**：所有建议回复仅引导至笔记商品卡、挂车或站内私信，**绝不包含微信、vx、电话等站外引流内容**
- ✅ **帮助合规经营**：店主的回复保持在平台内，不违反小红书社区规则

### 🚫 广告/导流（违反社区规则）

| 类型 | 关键词（中文） | 关键词（英文） | 处理建议 |
|------|----------------|----------------|----------|
| 站外引流 | 微信、v信、vx、威信、薇信、扣1、私我、主页看 | check my bio, dm me, telegram, whatsapp | **删除或不回复** |
| 营销广告 | 免费资料、日入、月入、兼职、躺赚 | make money, free stuff, giveaway | **删除或不回复** |
| 灌水 | first、沙发、前排、抢楼 | - | **删除或不回复** |

**重要说明**：

- 🚫 **不教规避**：本工具不提供谐音词典、QR码隐藏技巧或任何帮助规避平台审核的功能
- 🚫 **识别导流**：如果评论中包含微信、vx、威信等站外引流内容，无论是商家还是垃圾广告，都标记为「广告/导流」并建议删除

### 💬 其他

- 感谢/点赞：谢谢、感谢、太好了、真棒、thanks、love it、❤️
- 普通评论：不属于以上分类的其他内容

## 诚实说明

### ❌ Mystery House 不会做的事

- **不自动发评论或回复** - 那是垃圾行为，违反平台服务条款
- **不接小红书官方 API** - 小红书目前没有公开的评论 API
- **不教你绕过平台审核** - 我们遵守平台规则
- **不保证 100% 准确** - 分类基于规则，建议人工审核后再操作

### ✅ Mystery House 能做的事

- **帮你省时间** - 不用每天手动翻几百条评论
- **不漏商机** - 自动识别购买意向评论
- **清理垃圾** - 标记导流广告和灌水评论
- **提供建议** - 给出回复话术参考

### ⚠️ 使用限制

1. **需要手动复制粘贴评论** - 小红书和 Instagram 都不提供公开评论导出功能
2. **建议回复需人工审核** - 自动生成的回复仅供参考，请根据实际情况修改
3. **Stripe 配置后才能收款** - 未配置时显示演示模式，不会产生真实交易
4. **分类准确率取决于规则覆盖** - 边缘情况可能需要人工判断

## 开发和扩展

### 添加新分类规则

编辑 `lib/classifier.ts`，在 `PURCHASE_RULES` 或 `SPAM_RULES` 数组中添加新规则：

```typescript
{
  patterns: [/你的正则表达式/i],
  category: 'purchase' | 'spam',
  tag: '标签名',
  reason: '分类原因说明',
}
```
